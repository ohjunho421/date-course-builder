  ```

  ```

  ```

  ```

- appName (granite.config.ts의 `appName`과 정확히 일치해야 함):

  ```

  ```

- 앱 유형: `비게임`

## 노출 정보

- 카테고리 경로 (3단계): `생활 > 여행 > 기타`
  - 구현된 동작 기준: 장소를 모아 나들이/외출 코스(동선)를 계획하고 공유하는 기능.
  - 소셜 카테고리는 선택하지 않음 — 매칭/만남 기능이 없으므로 데이팅 서비스가 아님.

- 앱 검색 키워드 (7-10개, `app-seo-keywords` 규칙 적용):
  - `데이트코스` — 핵심 기능을 그대로 검색하는 헤드 키워드
  - `데이트` — 넓은 탐색 의도의 헤드 키워드
  - `코스짜기` — "코스 짜주는 것" 과업 검색 의도
  - `맛집` — 코스에 담는 대상(저녁/식당) 검색 의도
  - `카페` — 코스에 담는 대상(카페) 검색 의도
  - `기념일` — 특별한 날 코스 준비 의도(롱테일)
  - `나들이` — 연인 외 커플/친구 나들이 계획 의도
  - `주말` — "주말에 뭐하지" 시점 기반 검색 의도
  - `여행` — 카테고리 경로(여행)와 정합되는 키워드

## 출시 전 확인 필요 (정책)

- 토스 로그인: 앱인토스는 로그인 수단으로 토스 로그인만 허용. 현재 서비스는
  카카오 로그인을 사용하므로, 심사 통과를 위해 미니앱 진입 경로에서는 토스
  로그인으로 전환하거나 로그인 없는 흐름으로 조정 필요.
- 외부 링크: 장소 카드의 "네이버에서 보기", 구간별 네이버 길찾기 딥링크는
  외부 링크 제한 정책 검토 대상. 단순 정보 페이지 연결은 허용 예외에 해당할
  수 있으나 심사 기준 확인 필요.
- 번들 방식: 정적 셸이 호스팅된 웹 서비스(Railway)로 이동하는 구조.
  CSR/SSG만 지원하는 앱인토스 웹 번들 제약에 따른 구성으로, 심사 시 서비스
  URL을 함께 고지 권장.
