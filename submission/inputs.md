
## 출시 전 확인 필요 (정책)

- 로그인: **필요 없어요.** 누구나 로그인 없이 코스를 만들고, 공유하고, 상대의
  응답을 받을 수 있어요. 만든 코스는 이 기기(localStorage)의 "내 코스"에서 다시
  찾을 수 있어요. 로그인 반려 리스크가 없는 게 가장 큰 장점이에요.
- 토스 로그인(선택): 다른 기기에서도 코스를 보관·조회하고 싶을 때만 쓰는 옵션
  기능이에요. 앱인토스 WebView에서는 (제공한다면) 토스 로그인만 노출되고 카카오
  로그인은 숨겨져요. 활성화하려면 콘솔에서 토스 로그인 설정 후 mTLS 인증서를
  발급해 서버 환경 변수 `TOSS_MTLS_CERT_BASE64` / `TOSS_MTLS_KEY_BASE64`에 넣어야
  해요. 넣지 않으면 로그인 옵션 없이 익명으로만 동작해요.
- 공유: 앱인토스 WebView에서는 카카오톡 공유 대신 토스 공유 시트를 사용해요
  (외부 앱 이동 정책 대응).
- 외부 링크: 장소 카드의 "네이버에서 보기"와 길찾기 링크는 모두 웹
  URL(naver.me, map.naver.com)이라 WebView 안에서 열려요. 앱 설치를 유도하는
  딥링크는 없어요. 단순 제3자 정보 페이지 연결로 허용 예외에 해당하지만 심사
  기준 최종 확인 권장.
- 번들 방식: 정적 셸이 호스팅된 웹 서비스(Railway)로 이동하는 구조.
  CSR/SSG만 지원하는 앱인토스 웹 번들 제약에 따른 구성으로, 심사 시 서비스
  URL을 함께 고지 권장.
